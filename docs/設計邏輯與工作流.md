# 可視化辦公室：設計邏輯與工作流

這份文件不是要你做出一模一樣的辦公室，而是把「為什麼這樣設計」和「是怎麼做出來的」交給你，讓你的 AI 照你自己的團隊、工具和喜好，做一個屬於你的版本。

建議用法：把整份文件丟給你的 AI（例如 Claude Code），再告訴它你有哪些 AI、各自負責什麼、你喜歡什麼畫風。第八節有可以直接貼的開場白。

---

## 一、這是什麼

一個網頁，畫面是一間溫馨的小辦公室，每個 AI 是一隻小動物，你自己是老闆。你不用讀任何紀錄，看一眼就知道：誰在忙、誰閒著、誰卡住了、誰在找誰、有幾件事在等你。

核心想法只有一句：**AI 做的每一件事，都要有一個擬人化的動作對應**。看不到的事等於沒發生。

---

## 二、設計邏輯：每一種狀況長什麼樣

### 1. 狀態對照

| AI 的實際狀況 | 畫面上的樣子 |
|---|---|
| 在線、工作順利 | 坐在自己位子上打字，笑臉、臉頰紅潤 |
| 工作很重、快到極限 | 駝背、冒汗 |
| 沒事做 | 去休息區：喝飲料、吃餅乾、看電視、躺沙發、趴地毯看書（隨機輪流，不固定誰做什麼） |
| 不在線 | 座位空著，掛「外出中」牌 |
| 額度用完 | K.O. 倒地、眼冒金星，卡片寫幾點恢復 |
| 任務失敗 | 罵＊@∆×、捶桌、趴桌垂頭喪氣（三種輪流） |
| 人在，但訊息一直沒接 | 變半透明、下半身變鬼尾巴，掛「請勿打擾」 |
| 找不到人 | 走到對方門口敲門、冒問號 |
| 同時開好幾個對話 | 身後多出半透明分身，旁邊標「×4」 |
| 做完一件事 | 在位子上歡呼「做完了！」，再去休息 |
| 正在工作 | 兩隻手輪流動，像在打鍵盤；看書、看文件的人慢一點，像翻頁或寫字 |
| 找不到人、在等 | 在對方門口來回踱步，要用走路的腳步，不能整隻左右飄 |
| 每個人的額度 | 頭上的生命條（像電玩角色） |
| 等你處理的事 | 你桌上的公文夾，一件一個 |

### 2. 彼此互動

| 實際發生的事 | 畫面上的樣子 |
|---|---|
| A 傳訊息給 B | A 走到 B 那裡，頭上冒「💬 B」 |
| 派工 | 總協調拿著公文夾走過去，「📁 交給 B」 |
| 回報、交件 | 拿公文夾走去找總協調，「📁 回報」 |
| 對方在休息區 | 直接走去休息區找他，不是去空辦公室門口 |
| 談公事 | 被找的人要起身，兩人站著面對面 |
| 對方回話時你還站在他門口 | 他坐著回就好，不要兩人互相走到對方門口錯過 |
| 總協調收信 | 走到郵筒拿信 |
| 被關在沙盒裡的 AI 要找人 | 牆外的呼叫燈亮起「呼叫 某某」，被叫的人走到門外 |
| 你點某隻動物 | 跳出卡片，可以直接跟那個 AI 講話 |

### 3. 動作必須合理（這些都是實際踩過的坑）

- **不能飄**：移動一定是走路，沿著地板上規劃好的走道走，兩腳交替。
- **不能穿牆**：每間辦公室從出口進出。出口太窄就做一扇門，有人走近會開。
- **不能穿過彼此**：遇到人要停下來讓路或側身繞過。
- **先下椅子再走**：從椅子、沙發起身，先站到旁邊地板上才開始走；到了目的地站定才坐下。
- **被東西擋住要真的被擋**：走到隔板、櫃子後面，東西要蓋在角色上面。但要照物品實際形狀蓋，不能切成一條直線或一個方塊。
- **倒下要倒在合理的地方**：整隻躺得下的空地，不能倒在牆縫裡。
- **坐著工作要真的在工作**：人坐在桌子後面、面向觀眾，手放在鍵盤或文件上，眼睛看螢幕或文件。手懸在半空就不像在做事。
- **每樣東西都是固體**：角色、家具、牆、門、椅子、玻璃都會擋住它後面的東西；誰在前由「貼地的位置」決定。對話泡泡、名字、生命條不是固體，永遠在最上層。關在玻璃間裡的角色，玻璃要畫在他身上。
- **資訊不要擠在一起**：名牌、對話泡泡、呼叫牌分開放。

### 4. 空間

- 每個人一間辦公室，主題和顏色都不同，一眼認得出是誰的。
- 老闆的辦公室最大。
- 名牌是畫在圖裡的實物（門上掛牌、桌上立牌），牌面留空，字由程式填。
- 有公共休息區：沙發、電視、茶几、咖啡吧、按摩椅。
- 不能上網、碰不到你檔案的 AI，關在玻璃沙盒裡，裡面有自己的桌椅和休息角。
- 專案進度用右下角的火箭發射台表現：三個平台放最近有動靜的專案，有回報進度的畫燃料條，沒有的寫「加油中」。

**畫底圖之前先定好這些，不然事後補不完（這是花最多時間重做的地方）：**
- 每個工作位置：桌子在人和觀眾之間，人面向觀眾坐（才看得到表情）；螢幕放桌子側邊不擋臉；鍵盤在椅子正前方、伸手可及。
- 每個人都要有工作檯，不要有人只有椅子或懶骨頭。
- 每間辦公室有明確的出入口，寬度至少一個半角色寬，門前不放東西。
- 主走廊夠兩個角色交會；走道上不放落地燈、書堆、盆栽。
- 屋內地板要完整，不能有缺角。
- 沙發等可以坐的家具，正面朝觀眾、前方留地板。

### 5. 辦公室動態與每週之星

常常打開畫面時大家剛好都在休息，其實剛才發生了很多事。所以即時畫面下方再放兩樣東西：

- **辦公室動態九宮格**：每格是一件真的發生過的事（誰找誰、交代、回報、做完、卡住、額度用完），標「幾分鐘前」。每格是一個小鏡頭：同一張底圖裁切對焦在事件發生的位置，把當事角色擺出來。點開會放大重演，角色走過去、鏡頭由遠推近。新的進來就把最舊的擠掉。
  - 這是依紀錄重演，不是錄影，全部由網頁自己畫，不花任何 AI 額度。畫面上要寫明這一點。
  - 同兩個人短時間內的來回訊息合併成一格，不然很快被洗版。
- **每週之星榜單**：依本週上榜次數排名，第一名有表揚狀（他是誰、專長、這週做了什麼、特此表揚）。注意公平性：只靠某一種紀錄來源，沒接上那個來源的 AI 永遠上不了榜。

### 6. 誠實原則

- 沒有真實資料來源的東西，寧可顯示「沒有資料」，也不要放假數字。
- 推估的數字要標「推估」。
- 手動填的數字超過半天就不算數。

## 三、架構（很簡單）

- **一個網頁檔**：底圖一張，上面用 SVG 疊角色、遮蔽物、門、泡泡。
- **一支小伺服器**（Python 內建功能就夠，不用裝東西）：每幾秒收集一次各 AI 的狀態，整理成一份資料給網頁。
- **網頁每幾秒問一次伺服器**，依資料決定每隻動物在哪、做什麼。

三個關鍵做法：

1. **走道是一張「路口與連線」的圖**。每個位置記錄它接到哪個路口，移動時先算出要經過哪些路口，一段一段走。
2. **遮蔽物記兩樣東西**：它的輪廓，和它貼地的那條線。角色的腳在線的後面，就把東西畫在角色上面。
3. **狀態由資料推導**，不要讓 AI 自己回報「我現在很開心」。

## 四、資料從哪裡來（依你有的工具替換）

原則：**優先讀工具自己留下的紀錄，不要靠 AI 自己回報**。請 AI 回報的，常常會忘記、或回報寫死的數字。

| 想知道的事 | 實際做法 |
|---|---|
| 誰在線、誰在忙 | AI 之間的傳訊工具通常有「在線清單」指令；沒有的話看該程式有沒有在跑 |
| 誰傳訊息給誰 | 傳訊工具在本機的紀錄檔：只讀寄件人、收件人、時間、已讀與否，**不讀內文** |
| 訊息沒人接、找不到人 | 同一份紀錄：超過 5 分鐘未讀 → 寄的人去敲門，收的人變鬼 |
| 派工、交件 | 看訊息方向（總協調發出＝派工；發給總協調＝回報）；沒接傳訊工具的 AI 就看它的「輸入／輸出」資料夾有沒有新檔案 |
| 沙盒裡的 AI 忙不忙 | 它的工作紀錄檔兩分鐘內有沒有變動（只看時間，不讀內容） |
| 額度 | 工具本身的用量指令；查不到的就留白 |
| 等你處理的事 | 傳訊工具裡狀態是「等使用者回答」的對話數 |
| 點動物講話 | 各 AI 的命令列工具，伺服器代為呼叫一次、把回覆顯示在卡片上 |

隱私提醒：只讀「誰、何時、讀了沒」，不要讀訊息內文；機密資料不要經過這套系統。

## 五、美術怎麼做出來的

1. **先給 AI 看參考圖**，挑定畫風（這裡用的是精緻像素風、斜上方俯視的小屋）。
2. **先寫好規格再畫底圖**：把第二節第 4 點那張清單（工作位置、出入口、走廊）寫成文字規格交給畫圖的 AI。一張完整辦公室，不要有角色、不要有字，名牌留空。
3. **角色畫成「角色表」**：一隻動物一張圖，純綠色背景，十幾個姿勢排成格子（生氣、垂頭喪氣、K.O.、敲門、躺、喝飲料、吃餅乾、趴著看書……）。
4. **程式自動去背切圖**：把綠色去掉，一格一格切開，切好存起來，下次不用重切。
5. **缺姿勢時補畫，一定要附現有角色表當參考**，只要求改姿勢。只給文字讓它重畫，角色會長得不一樣。
6. **坐在桌前的姿勢**：畫成「只有上半身、手往右下方放在桌面」，定位點就是手，把手對在鍵盤或文件上。腿本來就會被桌子擋住，不用畫。
7. **走路要兩格**：一格「跨步」（兩腳一前一後）、一格「併腳」（兩腳收回身體下方、一隻微微抬起）。不要寫「左腳在前／右腳在前」，斜前方視角下兩隻腳長得一樣，畫出來會是兩張相同的圖。也不要用程式把腿鏡射去湊第二格，腿會斷開。
8. **只想改圖的一小塊**（例如某個房間的桌椅方向）：把那一塊裁下來單獨請它改，外框不變，再貼回原位。叫它改整張圖，其他地方會跟著跑掉。
9. **放不準的小東西單獨畫**：某張椅子、公文夾這類小物，單獨生成去背，再由程式定位。

**準備兩個以上會畫圖的 AI，而且知道各自有幾套額度。** 實際遇到的情況：一個的指令工具額度用完要等兩天，另一個當天畫了三十張後也被擋；最後是用前者的桌面 App（跟指令工具是不同的額度），由使用者自己貼提示詞、把圖傳回來，才把事情做完。

## 六、怎麼檢查（最重要的一節）

寫程式的 AI 看不到畫面，很容易「改完就說好了」。要求它：

- **每種狀態都要強制擺出來、截圖、放大看過**才能回報完成。
- 分清楚「確認了程式判斷」和「親眼看到畫面」，兩者不一樣。
- 動畫它只看得到靜止畫面，動起來對不對要你自己看一眼。
- 做一個「軌道疊圖」的檢查模式：把走道、站位、遮蔽物範圍畫在底圖上，一眼看出路線有沒有穿牆。
- 做一個「示範模式」：自動輪播各種狀態，方便你一次看完。
- 每次回報要講清楚：做了什麼、看過什麼、**什麼沒做或沒驗證**。
- 換底圖是大工程：所有座位、走道、出入口、遮擋、休息點都要重新量。先做一個「帶座標格的量測頁」會快很多。
- 改完一定要重新整理頁面確認沒壞。只改一行也可能讓整頁打不開。

## 七、跟 AI 一起做事的方式（比技術更重要）

這些是實際磨出來的規則，建議一開始就告訴你的 AI：

1. **持續做到做好、做完**，除非你喊停。一條路不通（某個 AI 做不到、聯絡不上、額度用完）就換下一個；都試過了才停下來告訴你，並提出替代方法。
2. **節省你的時間**：多個檔案打包成一個下載；要你貼的東西一次給齊；要你重複做的事，先做一個驗收通過再做其餘。
3. **問你事情一律給選項**，不要讓你打字回答。你沒回答就傳了別的訊息時，處理完要再問一次。
4. **不用猜的，要實測**：某個工具能不能用，真的跑一次看它回什麼。
5. **記錄每個 AI 的表現**：好不好溝通、交回來的東西穩不穩，寫成一張共用的表，之後派工先查表。
6. **要花錢、要對外發布、要刪東西之前，一定先問你。**

## 八、怎麼開始

把這份文件給你的 AI，然後說：

> 我想做一個可視化辦公室，請照這份文件的設計邏輯來做，不要照抄別人的畫面。
> 我的 AI 團隊有：（列出每個 AI 的名字、負責什麼、用什麼工具跑）。
> 我自己是老闆，想被畫成：（動物或樣子）。
> 我喜歡的畫風：（附參考圖或描述）。
> 請先問我不清楚的地方，再提兩種畫風讓我選。每做完一種狀態，都要截圖看過再跟我說。

建議的順序：

1. 先定角色和空間格局，畫底圖，你點頭再往下。
2. 畫角色表，接上去背切圖。
3. 做狀態對照（第二節第 1 張表），先用假資料把每種狀態擺出來給你看。座位先對好：手要放在桌上的東西上。
4. 做走道、出口、讓路、遮蔽。
5. 接真資料（第四節）。
6. 做互動（第二節第 2 張表）。
7. 做辦公室動態和每週之星。
8. 需要的話：手機也能看、加密碼的遠端快照。

## 九、可以選配的功能

- **手機看即時畫面**：用私人網路工具把手機連回家裡電腦，只有你的裝置連得到。
- **在別的電腦看**：定時上傳一張唯讀快照到有密碼保護的靜態網站。快照要拿掉工作內容和對話，只留誰在線、誰在忙。
  - 注意：這類託管服務多半是算額度的。每改一點就上傳一次、再加上太頻繁的自動上傳，一天內就可能把整個帳號的額度用完（連帶其他網站也不能更新）。先查清楚怎麼計費，集中修完再傳一次，自動上傳一小時一次就夠。只用手機看就夠的話，這項可以不做。
- **開機自動啟動**：讓小伺服器跟著電腦開機啟動、停了會自己重開，不要讓它掛在某一個 AI 對話底下（對話一關它就跟著關）。在 Mac 上，背景服務可能沒有權限讀「文件」資料夾，改由終端機來啟動就可以。
- **手機桌面圖示**：做成可以加到主畫面的網頁。
- **畫面放大縮小**。
